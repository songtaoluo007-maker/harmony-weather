# 专业复核 · 体验一致性改进

2026-09-08。落实用户确认的三项优先改进：信息一致、统一详情、天气氛围向下延续。
保留城市景观、天气动效、预报、全部生活入口、仪表、资讯与设置；不新增演示入口。

## 本轮实现

- 按 Product UI Design 统一材质与层级。下半屏、生活插画底色、仪表高光、详情面板
  根据所选城市当地时间与真实天气选择静态色板：昼夜、日出/日落附近、雨、雾霾与雪。
  复用现有分钟时钟，不增加逐帧循环；AQI 警示色不被环境色覆盖。
- 空气、生活与预警使用同一原生半屏详情，可展开、滚动、关闭与再次打开。
  大标题、内容与来源分层；六项污染物双列展示，数值和单位独立排版，保留 CO 的 mg/m³。
  未获得空气观测时间时明确显示未提供，不拿天气观测时间冒充。
- 滚动后保留紧凑城市/温度标题与城市切换入口。详情打开时暂停背景粒子动效；
  页面隐藏、销毁或发起刷新会关闭详情，防止旧城市内容滞留。
- 本地运动提示同时检查已知 AQI、天气、降水、风与体感温度。空气缺失/标准未知
  不再作出肯定的户外建议；污染或不利天气下保守提示室内活动。
  这些是产品规则，不是临床评分、个人健康评估或官方运动指数。
- 紫外线明确区分 `daily_max`、`daily`、`current`，不在夜间把全天峰值改成零。
  同城当天显示“今日峰值/今日预报”，跨日旧资料显示“预报峰值/逐日预报”；
  持续打开的首页和生活详情也随分钟时钟更新标签。缺失值不伪装成低强度。
- 内存与持久缓存恢复时重算本地提示，但不刷新原始数据时间。
  保留供应商指数和来源，只有与已知条件冲突的正面运动建议受到保守纠正。

## 运行证据

系统状态栏是 12 小时制，页面和数据时间为城市当地 24 小时制。

## 验证与边界

- 91 项测试通过：天气/缓存 55 项，其余覆盖资讯、页面生命周期、仪表、详情与色板。
  新增回归先复现再修复，涵盖 AQI 分档、无空气/异常数据、供应商保留、旧缓存与
  城市跨日、紫外线缺失/峰值、详情所有预警与来源、不伪造空气观测时刻。
  测试加载真实模型和 Service，平台 I/O 使用替身，不代表真实接口全链路验证。
- Hvigor `assembleHap`、SDK `6.1.1(24)` 构建成功；未签名 HAP 安装、重启成功。
- 原生检查覆盖生活卡片、空气/紫外线详情、关闭按钮、返回、再次打开、面板展开与滚动。
  窄屏检查修正了污染物单位拆行；原生按钮的圆角丢失和短详情居中留白也已修正。
- 只读独立 UI 代码复核未发现额外可执行问题；边界与未验证范围保留在这里。
- 原生本轮观察为当前夜间；白天、黄昏、雨/雾、其他时区用模型测试验证色板选择，
  不能代替每种天气的设备截图。完整读屏、2× 字体、390/480vp、横屏/平板与长时性能仍待验证。
- 未新增气象预警源。已有预警展示路径改为完整列表，无预警数据时不补造警报。
  和风接口仍预留，缺少用户密钥，账户联调未完成。现有免费数据的商业授权、
  正式签名和发布审查限制不变；本轮不是企业级上线认证。
- 更进一步的“天气事件时间轴”和新版昼夜仪表仅为后续创意，未计入本轮已完成内容。
