# 正式产品界面设计（用户已在对话确认）

采用“天气｜资讯｜设置”三个入口，延续现有原生 ArkTS、动态城市与天气视觉，不重建演示应用。
首页移除背景预览、开发配置及大段来源说明；保留天气全部模块、更新时间和离线提示。
若开发者显式配置 mock，界面仍标识示例身份，绝不把模拟数据当实况。

资讯采用用户确认的官方原文在线阅读方式：原生栏目入口，点击后 Web 组件读取官方站点。
不抓取新闻列表、重写原站 DOM、缓存转载文章或制造新闻标题。加载、重试、浏览器打开和返回可用。
Web 不注册原生 JS 桥，不开放文件、定位、摄像头、麦克风或第三方应用跳转。

设置提供温度单位、动态天气、更新频率、城市管理、定位权限、天气缓存清理、隐私和关于。
缓存清理仅清天气缓存，不删除城市/偏好/打包资源，清理失败不报成功。
关于集中显示数据来源、模型与 AQI 标准、图片署名及许可；隐私说明实际数据流，不虚构运营主体。

本轮是正式产品界面与功能建设，不等于商用上线验收。付费数据授权、新闻聚合授权、企业主体、
隐私法律审查、生产签名/发布、全球城市及预警后台均不通过此次前端改造自动完成。
