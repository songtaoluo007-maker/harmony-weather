# 功能保留回归：实施与验收清单

范围：补齐 2026-09-08 审计确认的六项缺失，保留当前 UI、在线数据、城市背景与原项目本地改动。
基线：改造前 99bd599 与当前 96b61b8。全球搜索、预警新数据源、城市排序和系统主题不混入本轮。

## 实施顺序

1. 先增加失败用例：风速与污染物显示模型、生活条目、夜间汇总及缓存、雪花运动。
2. 补回风速数值和六种污染物，同时保留风向/风级与单位；缺失显示暂无。
3. 恢复旅游与感冒入口，保留温差作为额外信息。无可靠来源时不生成适宜度或健康风险。
4. 从日落至次日日出的逐小时数据汇总夜间天气，并标注汇总范围和完整性。
5. 使用容器实测尺寸绘制飘雪，服从应用动效开关、页面生命周期与离屏暂停；恢复结构化骨架屏。
6. 原生模拟器逐项核对六项功能，运行状态测试、完整 Hvigor 构建与 Git 差异检查，再同步原草稿 PR。

## 验收项

- [x] 风速包含 km/h，保留风向与风级；0 不当作缺失。
- [x] PM2.5、PM10、NO₂、SO₂、CO、O₃ 可见且单位正确。
- [x] 穿衣、运动、紫外线、洗车、旅游、感冒均有入口；温差不冒充感冒指数。
- [x] 夜间汇总不混入前一天凌晨或白天，不用白天天气填充缺失数据。
- [x] 雪花确实下落/横向飘动，停用动效后画面稳定，按实测容器绘制。
- [x] 首次加载有温度、预报、卡片骨架，不展示默认温度作为实况。
- [x] 原有刷新、城市切换、预报详情及云雨场景继续可用。

本清单只声明实际完成的验收，不把编译成功等同于功能全部保留。

## 边界

本轮原生截图为 Pura 90 模拟器约 377vp 宽度。雪粒位置模型覆盖 320/360/390/480 宽度，
不等同于所有页面的大字体、横屏、平板或真机性能验收。页面隐藏/离屏停止由生命周期代码控制，
未进行长时间功耗测试。没有有效和风密钥，未重新联调该账户接口。

旅游/感冒恢复的是入口与诚实的无数据状态，不是已接入官方指数。其他生活提示仍为本地规则；
Open-Meteo 夜间信息为逐小时数据汇总，不冒充独立官方夜间产品。极昼极夜或缺少太阳时刻时显示暂无。
