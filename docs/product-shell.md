# 正式产品界面交付 · 2026-09-08

本轮依据已确认的“天气｜资讯｜设置”方案落地，使用 Product UI Design 整理导航、信息层级与操作文案。
原生 ArkTS 工程和真实天气数据源保持不变，不以网页替换天气应用。

## 用户可见变化

- 首页删除背景预览入口、预览覆盖参数、开发配置及大段演示/来源说明。保留更新时间、必要的离线提示、天气全部模块及动态城市背景。
- 设置为独立主入口：城市管理、系统定位权限、摄氏/华氏、动态天气、15/30/60 分钟更新、天气缓存清理、隐私、关于。
- 清理前确认，只清天气数据，不删除选中城市、城市列表、显示偏好或城市图片。存储失败返回失败提示；并发读取与旧请求写入受到保护。
- 资讯提供天气新闻、气象科普。点击后读取中国天气网官方移动网页，保留原站内容/来源/版权，不抓取列表、不打包新闻快照、不虚构标题日期。
- 关于集中展示实际版本、天气和 AQI 来源、指标口径、城市图片及图标许可。隐私说明真实数据流，不虚构运营主体或已经完成的法律审查。

## 官方阅读与边界

频道入口来自[中国天气网移动版工具箱](https://m.weather.com.cn/e_index/listnav.html)：
[新闻](https://m.weather.com.cn/news/index.shtml)、[科普](https://m.weather.com.cn/news/kp.shtml)。
发布方有明确的[版权声明](https://www.weather.com.cn/wzfw/banquan.shtml)，本版本只提供原站阅读，不提供转载聚合服务。

主页面仅允许 `m.weather.com.cn`、`news.weather.com.cn`、`www.weather.com.cn` 的 HTTPS；
可信主机的旧 HTTP GET 链接先取消再升级 HTTPS。拒绝伪造后缀、用户信息、非默认端口、自定义协议。
拦截外链保留正在阅读的页面和返回历史。浏览器打开仅由用户点击原生按钮触发，并再次验证 URL。

阅读器使用临时会话，不注册原生 JS 桥；禁用文件、混合内容、定位、文件选择、下载及新窗口，拒绝敏感权限、录屏与证书异常。
官方脚本及 HTTPS CDN 资源可运行/加载；这不是对发布方内容的无追踪保证，隐私页已说明第三方网络访问。
原站旧 HTTP 图片会被阻止，部分文章和视频可能排版/播放不完整；不会为此降低连接安全性或改写网站 DOM。
有刷新、20 秒加载超时、失败重试和外部浏览器入口。外部浏览器采用其自身权限与隐私设置。

## 实际验证

- DevEco SDK 6.1.1(24) 完整模块 `assembleHap`；未签名 HAP 安装至 Pura 90 模拟器运行。
- 三套 Node 测试共 52 项通过（34 天气、14 资讯、4 页面生命周期），运行真实模型、Service 和页面非渲染方法，平台 I/O 为替身；覆盖天气分源缓存、缓存清理竞态、网页 URL/加载状态、页面销毁后的异步回调及返回历史。
- 原生检查天气/资讯/设置切换、新闻原站与文章、刷新、网页返回与外部浏览器、设置单位保存、缓存取消/确认、系统应用权限入口、隐私、当前与全部城市署名。
- 清理缓存后回到青岛在线天气，华氏显示 72°；恢复摄氏后为 22°，选中城市未丢失。
- 从设置进入城市管理切换北京，首页同步到北京 20°/阴；搜索青岛后恢复原选中城市。
- [实际界面总览](../design/product-shell.jpg)，[新闻原站阅读](../design/product-reader.jpeg)。
- 青岛夜间晴间多云，[18 帧动态实录](../design/product-cloud-motion.gif)跨度约 15.56 秒，云层位置变化；不是性能帧率测试，未使用天气预览覆盖。
- 设置、资讯在约 377vp 实际视口及临时 320vp 父容器中检查，文字与按钮无横向裁切。320vp 证据为窄容器 smoke test，右侧白色为容器之外的设备区域，不冒充 320px 真机。
- 临时窄容器钩子已移除。此轮未完成全尺寸/大字体/横屏矩阵、真实存储故障、设备断网/恢复、证书故障注入、耗电或长时间压力测试。

## 商用前仍需完成

这次是正式产品界面与功能建设，不是“企业级商用上线已验收”的声明。
免费 Open-Meteo 托管端点[限非商业使用](https://open-meteo.com/en/pricing)，商用需要获授权的数据服务和生产代理配置；和风保留本地配置入口，尚无可用密钥联调。
仍需正式签名、运营主体及隐私审查、完整资源许可核验、监控/发布体系及真机质量矩阵。
当前目录仍为 15 城市，不含全球搜索、官方预警后台、拖动排序或新闻聚合授权。
早期 README 中的预览/演示截图是历史验证资料，不是新版应用入口或当前天气。
